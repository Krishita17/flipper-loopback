# Rig jig (Phase 3)

The jig holds the emitter and DUT at a fixed distance and orientation so RF/IR results repeat from run to run. STL/STEP files and wiring notes will go here in Phase 3.

Until then, bench setup for Phase 1:
- Put the two Flippers 10–30 cm apart, back to back, on a non-metal surface.
- Use internal CC1101 on both (device index `0`).
- Use short, data-capable USB-C cables to the host.
